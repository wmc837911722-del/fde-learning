# FDE Learning course override

The generated master system remains the baseline for hierarchy, spacing, accessibility, responsive behavior, and minimal motion. This project adds a deliberate brand override so the learning product is visibly connected to Fengyu's existing FDE service site.

## Brand color override

- Dark background: `#080B12`
- Dark surface: `#101520`
- Light background: `#F7F7F2`
- Primary blue: `#4D6BFF`
- Bright blue: `#7288FF`
- Dark text: `#10131A`
- Light text: `#F8F8F4`

Do not use the generated teal/orange palette. The existing blue palette already meets the brand-recognition requirement and will be checked for WCAG contrast in both themes.

## Course-specific rules

- Use documentation-style hierarchy, built-in search, breadcrumbs, deep links, and visible previous/next navigation.
- Keep the primary journey focused on learning; links to commercial services are secondary and contextual.
- Do not add GSAP or decorative scroll reveals to lesson content.
- Use progress through deliverables and rubrics instead of badges or superficial gamification.
- Keep touch targets at least 44px and preserve visible keyboard focus.
